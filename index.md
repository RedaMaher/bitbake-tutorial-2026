# A Practical Guide to BitBake

## Updated for BitBake 2.18 and Python 3.14

This article documents my work updating and validating a standalone
BitBake learning project for a modern 2026 environment.

The project was based on Harald Achitz's original
[A Practical Guide to BitBake](https://a4z.noexcept.dev/docs/BitBake/guide.html).

## Tested environment

- Ubuntu 26.04 LTS
- Python 3.14.4
- BitBake 2.18.0
